# GEO 雷达 — 出海品牌 AI 能见度平台

一个**可直接上线售卖**的完整 SaaS。帮中国出海品牌看清自己在 ChatGPT / Gemini /
Claude / Perplexity 里被不被推荐、被谁抢了风头,并一键生成补救内容。

---

## 一、这套交付物包含什么

```
geo-radar/
├── backend/                    # Python FastAPI 后端(已通过语法+逻辑验证)
│   ├── main.py                 # API 主入口:账号、品牌、监测、报告、内容生成
│   ├── database.py             # 数据模型 + 三档套餐配额
│   ├── services/
│   │   ├── monitor.py          # ★核心:AI 能见度监测引擎(已通过算法测试)
│   │   ├── generator.py        # 问题集生成 + 缺口内容生成
│   │   └── knowledge.py        # 官网自动抓取建库(零上传)
│   ├── requirements.txt        # 依赖清单
│   ├── .env.example            # 环境变量模板
│   └── Dockerfile              # 容器部署
└── frontend/
    └── index.html              # 完整单页应用(商家4步操作界面)
```

## 二、5 分钟本地跑起来

```bash
cd backend
cp .env.example .env            # 然后编辑 .env,填入至少一个 AI 平台密钥
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

浏览器打开 `http://localhost:8000` 即是商家登录界面。
API 文档在 `http://localhost:8000/docs`(FastAPI 自动生成)。

## 三、上线生产(任选其一)

**A. Docker(推荐)**
```bash
cd backend && docker build -t geo-radar . && docker run -p 8000:8000 --env-file .env geo-radar
```

**B. 云服务器**
配 Nginx 反代 + Postgres + HTTPS 证书即可。把 `.env` 里
`DATABASE_URL` 改成 Postgres 连接串,代码无需任何改动。

## 四、上线前你必须补的 3 件事

这套代码是**完整可运行的产品骨架**,但商业上线前还需:

1. **填入真实 AI 密钥**(`.env`)——这是监测能跑的前提。成本预估:
   每个品牌 50 问题 × 4 平台 ≈ 200 次调用,约 ¥3–8/次完整监测,
   按周监测一个品牌月成本约 ¥15–35,售价 ¥199 起,毛利充足。
2. **接支付**——代码已预留三档套餐(`database.py` 的 `PLANS`),
   接微信支付/支付宝/Stripe 后,支付成功回调里改 `user.plan` 即可。
3. **密码加盐**——当前用 SHA256 演示,生产请换 `bcrypt`(一行替换)。

## 五、为什么这个产品能卖(市场依据)

- 58% 消费者已用 AI 代替传统搜索找推荐,48% B2B 买家靠 AI 发现供应商。

     全行业评测都指出对手"只告诉你有没有,不告诉你怎么办"。
  2. **出海专属**——中文界面+中文顾问+出海场景问题模板,海外工具不做。
  3. **实惠**——入门 ¥199 对齐市场地板价,企业版只到对手一半。

## 六、合规红线(已写进代码,营销不可越界)

1. **只用官方 API**,不爬 AI 网页、不模拟登录——稳定且合规。
2. **数据标口径**——报告底部强制显示采样次数和"非绝对精确"声明。
3. **不承诺排名**——只给"被提及概率/竞品份额/引用来源"真实指标。
4. **社媒只给草稿**——`generator.py` 生成建议稿,人工审核发布,不自动铺量。
